Nexu

AI Desktop Assistant for Windows — Full Pipeline

Phase 1 — Voice Loop

DONE Core conversation: hold F4 → speak → hear response.

  • config.py — API keys, mic settings, paths
  • stt.py — record mic audio, transcribe via Groq whisper-large-v3-turbo
  • ai.py — AI brain (Groq primary, fallback: OpenRouter → Gemini → LM Studio). Streaming support.
  • tts.py — edge-tts voice output via pygame, sentence-by-sentence with interupt (F4 barge-in)
  • main.py — System tray overlay window (acrylic), F4 voice mode, F3 text mode

Phase 2 — Tool System

DONE AI emits structured JSON tool calls; Python executor runs them.

  • tools/system.py — launch_app, get_battery, get_cpu, get_ram, set_volume, notify, run_command
  • tools/files.py — open_file, open_in_vscode, search_files, get_file_info, list_directory (fuzzy path matching)
  • tools/browser.py — open_url, search_web
  • tools/executor.py — tool registry, JSON parsing, execution dispatch

Phase 3 — Memory

DONE Persistent memory in ~/.nexu/memory.db using SQLite only.

  • memory/store.py — Key-value facts: save/get/get_all/delete (uni portal, name, projects)
  • memory/vector.py — Conversation history with FTS5 full-text search. Past conversations auto-injected into AI context

Phase 4 — WhatsApp + Browser Automation

DONE Playwright-based automation for real-world interaction.

  • tools/whatsapp.py — send_message (by name or number), read_recent_messages, list_contacts. Session persists across restarts via saved storage state. QR scan on first run.
  • tools/browser_automation.py — AI-guided browser navigation: extracts DOM text → Gemini decides what to click → loops until goal is met. Auto-login detection with saved credentials.

Phase 5 — Polish & Packaging

NEXT Make it feel like a real product — robust, fast, packaged as a single .exe.

Below is the complete step-by-step plan. Each step builds on the previous one.

Step 1: Error Handling & Graceful Degradation

Goal: Nothing crashes silently. Every failure has a user-friendly fallback.

  • Microphone unavailable: Detect at startup, show "Mic not found" notification, fall back to text-only (F3) mode
  • AI API down: If Groq fails, auto-fall back through OpenRouter → Gemini → LM Studio (already partially done — needs better per-provider timeout handling)
  • Network offline: Detect connectivity before API calls. If offline, switch to LM Studio local mode, limit available tools to offline-only
  • Tool execution fails: Catch per-tool exceptions and return friendly messages like "I couldn't open that file — does it still exist?" instead of raw tracebacks
  • No API keys: Show a configuraton window on first run if no API keys are set, instead of silently failing

Step 2: Voice Improvements — VAD & Noise Gate

Goal: Stop holding F4. Just talk naturally.

  • Voice Activity Detection (VAD): Replace the current "hold F4 to record" with a "press F4 once to toggle listening". Use webrtcvad or a simple energy-based VAD to detect when speech ends and auto-stop recording
  • Noise gate: Apply a pre-recording filter that ignores ambient noise below a configurable threshold. Prevents "silence transcription" where the AI tries to interpret fan/AC noise
  • Result: Press F4 once → start talking → stop talking → automatic processing. Feels like a walkie-talkie, not a push-to-hold

Step 3: Interruption — Barge-In

Goal: Cut Nexu off mid-sentence and it listens immediately.

  • Currently F4 while speaking stops TTS and starts listening (already works in main.py)
  • Add voice barge-in: While AI is speaking, monitor mic for loud input (above a threshold). If detected, auto-stop TTS and start recording without requiring an F4 press
  • Add configurable "interruption sensitivity" setting

Step 4: Wake Word (Optional)

Goal: "Hey Nexu" activates the assistant without any key press.

  • Use a lightweight wake word engine — two options:
    • Porcupine (by Picovoice) — runs offline, ~2MB RAM, pip install pvporcupine. Free tier allows custom wake words
    • OpenWakeWord — MIT licensed, smaller model, can train custom phrases
  • Wake word runs in a background thread. On detection, triggers the same audio pipeline as F4
  • Make it togglable (hotkey-only mode vs wake word mode) via config

Step 5: Configuration UI

Goal: Change settings without editing .env files.

  • Build a simple settings window using Tkinter (already a dependency via pygame/Tkinter):
  • Settings panel:
    • Hotkey selector (F4 / Caps Lock / F3 / etc.)
    • AI provider dropdown (Groq / Gemini / OpenRouter / LM Studio)
    • API key fields (masked input)
    • Microphone device selector
    • Wake word on/off toggle
    • Voice speed/pitch
  • Migrate from config.py hardcoded constants to a config.json file in ~/.nexu/
  • Show settings window on first run if no API keys configured

Step 6: Logging & Debugging

Goal: Track down issues without staring at a console.

  • Create logs/ directory under ~/.nexu/ with daily log files
  • Replace all print() calls with Python's logging module (with timestamps, levels)
  • Add --debug CLI flag to show full logs in console
  • Save audio snippets from failed STT attempts for debugging (with auto-cleanup after 24h)
  • Log AI API response times and tool execution times to a CSV for performance tracking

Step 7: Performance Optimization

Goal: Idle under 200MB RAM, startup under 3 seconds.

  • Lazy imports: Only import tool modules when their first tool call is made, not at startup
  • PyAudio warm-up: Pre-initialize PyAudio in background thread during startup
  • Model preloading: Pre-load whisper model on app start (already partially done with preload_model(), but currently a no-op since STT uses Groq API not local whisper)
  • Connection keepalive: Maintain persistent HTTP sessions for Groq/Gemini APIs to avoid TLS handshake overhead
  • Profile memory: Use tracemalloc or psutil to measure and optimize memory usage

Step 8: Extra Tools

Goal: Give Nexu more useful abilities.

  • Clipboard: clipboard_read() / clipboard_copy(text) — read or set clipboard content
  • Screenshot: take_screenshot() — capture screen and save to temp file. Can pair with AI to "what's on my screen?"
  • PDF reader: read_pdf(path, pages) — extract text from PDF via PyMuPDF or pdfplumber
  • Volume mute/unmute: Quick toggle for mute
  • Wifi info: Show connected SSID, signal strength

Step 9: Packaging — PyInstaller .exe

Goal: One .exe file. No Python required. Double-click to run.

  • Create a build.py script that runs PyInstaller with all necessary hidden imports
  • Handle PyInstaller's quirks:
    • --hidden-import for dynamic imports (pyaudio, plyer, pycaw, comtypes, etc.)
    • Bundle .env as default config or embed defaults in the binary
    • Set --onefile --windowed --uac-admin if needed for volume control
    • Use --icon=nexu.ico for a proper icon
  • Test the .exe on a clean Windows VM to catch missing DLLs or dependencies

Step 10: Windows Auto-Start & Installer

Goal: Nexu starts when Windows starts. Clean installer for distribution.

  • Auto-start: Add a registry entry in HKCU\Software\Microsoft\Windows\CurrentVersion\Run with a "Launch at startup" toggle in the config UI
  • Installer: Use Inno Setup or NSIS to create a proper installer:
    • Copies .exe to Program Files
    • Creates Start Menu shortcut
    • Optionally adds to PATH for CLI access (nexu command)
    • Optionally adds desktop shortcut

Step 11: System Tray & Menu

Goal: A proper tray icon with right-click options.

  • Add an icon (static or animated during listening/speaking)
  • Right-click menu:
    • Open Nexu (show overlay)
    • Settings (open config window)
    • Toggle wake word
    • Mode: Voice / Text / Both
    • Exit

Verification Checklist for Phase 5

  • Single .exe runs on clean Windows install (no Python)
  • Startup time < 3 seconds
  • RAM < 200MB idle
  • No console window in release mode
  • Mic unavailable → text-only mode with notification
  • All APIs down → user-friendly message, no traceback
  • Wake word activates correctly (if enabled)
  • VAD stops recording naturally after speech ends
  • Interruption works (speak while AI talks → it stops and listens)
  • Config UI saves and loads settings correctly
  • Logs written to ~/.nexu/logs/
  • Auto-start with Windows works
  • All extra tools (clipboard, screenshot, PDF) work
